# Breakthrough

A paper dart plane smashes through the night sky, and daylight pours through the break it tears. The sky cracks, glass flies, and a comet trail streams behind the plane as it bursts from dark into dawn. Drawn from scratch in pure Python, standard library only, no image files, no text.
